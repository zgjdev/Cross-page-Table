# 跨页表格文献综合分析

评审日期：2026-08-02。结构化证据库见 [`papers.csv`](papers.csv)；数据库访问情况、结果数量、失败记录以及两轮引文滚雪球检索记录见 [`search-log.csv`](search-log.csv)。

## 任务分类

现有文献可分为六类任务，不应将这些任务混为一谈：

1. **续接检测**判断相邻页面上的表格片段是否属于同一个逻辑表格。PubTables-v2 使用 ViT-B/16 表格对分类器进行训练；Qin 等人使用 BERT 进行语义匹配；VCCT 则利用表头、边框和前页上下文。
2. **页面级抽取**检测页面中的表格并恢复其内部结构。PubTables-1M/TATR、GTE、POTATR 和 VLM 页面解析器均属于此类。
3. **片段合并**组合已经抽取出的页面片段。已发表的 PubTables-v2 基线和 POTATR 附录均先作出续接判断，再进行纵向拼接。
4. **结构对齐**确定列之间的对应关系、首行是否为重复表头，以及逻辑行是否在分页处被拆分。已评审的公开基准均未直接监督上述全部关系。
5. **层次化文档解析**预测页面或文档对象之间的阅读顺序和父子关系。DocParser、HRDoc、DocHieNet 和 Detect-Order-Construct 提供了相关方法，但并不恢复跨页表格的内部拓扑。
6. **文档级表格恢复**为每个逻辑表格输出一个可审计的表格对象，其中包含页面归属、单元格拓扑与内容以及跨页对应关系，并对最终重建对象进行评测。这是现有证据所支持的目标任务。

因此，实际流程应为：

`版面对象 -> 页面表格结构 -> 续接候选 -> 结构对齐 ->`
`文档表格图 -> 重建表格`。

续接只是图中的一种关系，而非最终任务。

PubTables-v2 是已评审的公开基准中唯一专门面向多页表格抽取的数据集。其规模足以支持续接和文档级评分，但由于缺少多片段表格的行列边界框，显式跨页对齐标签必须通过派生、弱监督或在受控子集上人工补充获得。这是潜在的研究贡献，也是主要实施风险，而非可以略过的预处理细节。

## 页面级抽取方法

与本研究相关的页面级方法可归为三种范式。

- **检测/图模型。** PubTables-1M 的 Table Transformer 预测表格对象以及行、列、单元格和表头边界框。TGRNet 与 GraphTSR 预测逻辑位置或单元格关系。POTATR 将 DETR/TATR 扩展为联合预测页面级表格、行、列、单元格、标题、表尾和层次边。POTATR 是目前最有直接相关性的轻量组件：其参数量为 29M，在 PubTables-v2 Single Pages 上报告 `GriTS_Con = 0.964`。
- **分割与拆分/合并模型。** CascadeTabNet、TableNet 和 RobusTabNet 恢复表格区域或单元格网格。它们的“合并”操作针对单个表格内的单元格，而非跨页面的表格片段。
- **自回归结构生成。** PubTabNet EDD、TableFormer、SmolDocling、dots.ocr 和更大规模的 VLM 生成 HTML、markdown 或文档标签。它们能够利用全局视觉/文本上下文，但若不显式输出边界框，其输出的有效性和空间约束较弱。

由此得到的主要启示是，新项目不应将研究贡献投入到替代已有的强页面抽取器上。应由 POTATR/TATR 或其他可复现解析器提供页面对象，新模型则处理这些对象的节点、不确定性、几何与文本信息。

## 跨页关联与合并方法

直接相关的方法数量不多，但均十分重要：

- **Qin 等人（2024）**对财务 PDF 表格进行分割，并使用类似 BERT 下一句预测的语义匹配来识别续接。该方法提供语义证据，但属于两阶段、领域特定的决策系统，既没有版面层次结构，也没有结构化表格恢复指标。
- **PubTables-v2（2025）**提供 9,866 个正样本和 5,964 个困难负样本相邻页面对。其 ViT-B/16 续接分类器达到约 `F1 = 0.991`。Full Documents 上，Claude Opus 4.6 报告最高内容 exact `Acc_Con = 0.2452` 和结构 exact `Acc_Top = 0.5799`；Gemini 3.1 Pro 的最高软相似度 `GriTS_Con = 0.9309` 不能解释为 93.09% 的表完全正确。
- **VCCT（2026）**在电网故障报告中融合前页/文档上下文，并对表头与边框进行预识别。其报告的结构完整性由 77.2% 提升至 82.0%，但使用私有领域数据和非标准复合指标。
- **POTATR（2026）**将 PubTables-v2 的续接/纵向合并方法应用于更强的页面抽取器。其 Full Documents `GriTS_Con` 从 0.671 提升至 0.827；在更新后的附录实验中，dots.ocr 从 0.577 提升至 0.750。POTATR 报告的续接召回率为 0.995，并将剩余差距归因于分布外多页内容和页面内片段合并。
- **LingDT-VL-OCR（2026）**在 FinDocBench 的 472 张跨页表格上，先逐页解析再使用列数、页面间正文和表头规则进行自适应合并，报告平均 `TEDS = 0.8915`。这是目前找到的最直接跨页子集软相似度结果，但论文未报告 exact match、同一子集基线或公开数据/代码链接。

这些结果表明，“更好的续接分类”不足以构成论文的核心主张。但它们并未证明显式列对应、重复表头处理或拆分行恢复已经得到解决。已发表的合并方法被描述为简单纵向拼接。

## 层次化与图式文档解析

DocParser 表明，可以联合预测页面实体和层次关系，其弱监督方法显著改善了实体 mAP 与关系 F1。HRDoc 将层次结构扩展到多页文档，并提供行级类别与关系标签。Detect-Order-Construct 统一了对象检测、阅读顺序和树结构构建。DocHieNet 则将文档层次数据扩展到单一模板族之外。

GraphTSR 和 TGRNet 表明，表格结构适合用单元格关系和逻辑行列坐标表示。DocGraphLM 表明，重建的文档邻域有助于信息抽取。RelationFormer 提供了通用的端到端图像到图结构范式；POTATR 则证明，基于 DETR 的文档图像到图结构模型能够兼具效率与空间落地能力。

在已评审的系统中，没有任何一个系统在单一文档图中联合预测以下全部内容：

- 页面版面层次结构；
- 跨页逻辑表格归属；
- 跨片段列对应关系；
- 重复表头身份；
- 拆分行/单元格续接关系。

这是最具可辩护性的模型层面研究空白，前提是评测对象为重建后的文档表格，而不只是边分类结果。

## 多页视觉语言模型

MMLongBench-Doc 表明，长篇多模态文档仍然难以处理：该研究中表现最好的模型仅达到 42.7% F1，并且 33.2% 的问题需要跨页证据。mPLUG-DocOwl2 将每页压缩为 324 个视觉 token，并采用多图像训练，使首 token 延迟降低超过 50%，同时改善了多页问答性能。这些工作展示了有价值的跨页上下文建模能力，但输出的是答案，而非可审计的表格结构。

SmolDocling、dots.ocr、olmOCR、Granite Vision 和 DeepSeek-OCR 是较强的页面转换基线，其主要输出为标记语言或线性化文本。PubTables-v2 与 POTATR 表明，全篇文档前沿 MLLM 的表现可以很强，但成本、输出有效性、可复现性和空间归因仍值得关注。公平的论文评测应纳入 PubTables-v2 中的全篇文档 MLLM 结果作为性能上界或竞争性基线，而所提方法的优势应体现在显式结构、空间落地、可训练性和确定性评测上。

## 指标与评测方案

现有任何单一指标都无法覆盖完整目标。评测应分为三个层次：

1. **诊断性边指标：**续接精确率/召回率/F1；列匹配 F1；重复表头 F1；拆分行关系 F1。这些指标用于揭示失败原因，但不应作为核心指标。
2. **链与图指标：**逻辑表格聚类/链 F1、按关系类型划分的边 F1、图编辑或树一致性指标，以及无效图比例。
3. **最终重建指标：**文档级 `GriTS_Top`、`GriTS_Con`、TEDS/TEDS-Struct，在可行情况下报告精确拓扑/内容准确率，并按跨页数、单元格数、重复表头、拆分行和页面版面复杂度分层报告性能。

与仅使用精确匹配相比，GriTS 更合适，因为它比较表格矩阵，并分别衡量拓扑、位置和内容。但仍需加入文档级匹配和面向对齐的错误报告。PubTables-v2 官方匹配/评测代码应作为兼容性基准。

所有数据划分必须至少以文档为单位。除官方划分外，还应报告在无测试泄漏前提下构建的模板不相交或期刊/模板簇不相交划分。聚类特征和阈值必须仅使用训练数据确定，近重复页面或源论文不得跨越不同划分。

## 模板泛化与捷径风险

DocLayNet 量化了领域问题：仅使用科学文献版面数据训练的模型无法可靠迁移到多样化版面。Document Domain Randomization 表明，即使语义保真度较低，版面风格不匹配也会降低准确率。Aligning Benchmark Datasets 表明，在模型不变的情况下，仅标注规范差异就可使精确匹配结果从 69% 变为 81%。Shortcut Learning 和 Data Leakage in Visual Datasets 则解释了为何独立同分布准确率和页面随机划分可能产生误导。

对于 PubTables-v2，潜在捷径包括期刊模板、页面位置、重复页眉、稳定的表格宽度、相邻页码和近乎相同的正样本片段。困难负样本相邻页面对有所帮助，但不足以证明模板泛化能力。必须采用以下控制措施：

- 仅按文档划分；
- 模板/期刊簇不相交评测；
- 对图像、几何、文本、页面位置、表头相似度和页码线索进行消融；
- 页面乱序和非相邻负样本测试；
- 按未见模板簇和表格跨页数报告性能；
- 训练前进行重复项/模板相似性审计。

## 证据支持的研究空白

现有证据支持一项**经过修订且范围更窄**的主张：

> 通过在版面与表格对象上预测类型化文档关系图，恢复英文原生数字化学术 PDF 中的多页表格；显式建模跨页列、重复表头和拆分行关系，并在文档不相交和模板不相交的方案下评测最终重建表格。

获得支持的新颖性并非使用图本身，也不是以更大的模型替代 ViT，而是以下要素的结合：(a) 最相近公开基线所缺少的显式结构对齐关系；(b) 与页面版面/表格对象的集成；(c) 结构感知重建；(d) 在抗泄漏划分下，将文档级提升归因于上述关系的评测。

最小可发表单元包括：可复现的 PubTables-v2 对齐子集/方案、强 POTATR/TATR 加纵向合并基线的复现、对齐感知关系模型，以及文档级评测/错误分类体系。第一篇论文不需要构建单体式端到端全篇文档 VLM，也不需要新的通用页面解析器。
