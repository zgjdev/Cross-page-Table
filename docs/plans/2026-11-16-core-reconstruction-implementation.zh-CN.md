# 2026-11-16 核心重建实现阶段

依据11月9日研究方案§4.3–4.6及用户确认的执行顺序，推进规范化网格直接基线和共同结构模块。现有HTML对照与全部历史结果保留。不以人审待完成为由停止代码、合成测试与接口验证；扩大真实训练仍执行原研究关口。

1. `grid_sequence.py`：严格global-grid-v1 JSON与既有Grid双向转换，复用完整占用/span验证，确定性HTML序列化。拒绝重复键、非有限值、额外字段、非法网格，文本和header角色保留。
2. `sft_data.py`及受限训练入口：显式输出格式选项，默认HTML兼容旧记录；grid目标仅进入assistant监督，prompt同生成入口共用，格式写入恢复配置，禁止跨格式续训。
3. `structure_memory.py`：共同有序列槽读取视觉和局部节点证据，槽间交互、节点回读；预测列数软门控，64槽+16摘要投影成结构前缀。首先验证mask、batch、证据敏感性、梯度、实际优化和重载。
4. 真实Qwen接口：读取既有train_fit素材，验证直接grid的processor与训练；结构前缀接入须独立核验mRoPE/attention/cache与逐token一致性，不能用单独模块测试冒充已集成。
5. 配对实验：同骨干直接grid、共同结构前缀、等长普通memory；后续遮蔽其他页证据。研究成绩以实际运行产物为依据，技术测试不代表方法收益。

每项先测试再实现，独立审查后运行服务器验证；代码先本地、数据只在服务器、新输出目录、不覆盖旧产物。每个可验收阶段更新研究记忆/进度索引/实验记录。当前状态为执行中，尚无本轮模型结果。
