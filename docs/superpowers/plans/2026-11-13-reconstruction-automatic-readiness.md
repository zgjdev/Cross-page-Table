# 联合重建自动化就绪推进

依据已批准的2026-11-09研究方案和11月13日评分预检。用户要求持续推进到可开始全量实验，并明确暂时无法安排两位审计者，先完成自动化部分。该指示不等于独立人审已经通过；不得自动放宽G0/G1或宣称全量训练就绪。

## 执行顺序

- [x] 独立规范网格层：明确HTML接受/拒绝策略、span/空格/实体、资源上限、语义往返，合成与200个train目标审计。
- [x] R0固定group评分：全部N分母、缺失/重复/非法失败、内容/拓扑/来源分别记录，明确是项目诊断而非已核准官方Acc。
- [x] 只读精确文本污染清单：train内划分及官方跨split仅指纹对账，不调整test规则；近重复、视觉和预训练污染另列待核验。
- [x] 真实裁剪图Paddle入口：只读取input和图像，固定权重/环境/参数，先2–4表，验证实际输出与GPU资源，不拿历史全页预测冒充R0。
- [x] B0纯纵向拼接与评分闭环：同列数保留所有文本/span/重复表头，异常保留分母；后续再实现强规则比较。
- [ ] 逐阶段留痕、独立代码审查、服务器核验、提交同步。原始数据与旧产物不变，所有run独占新目录。

方向首轮明确为preserve_original；侧向表不静默转正，后续方向对照须记录变换并同等应用所有方法。当前200表为暂定train_fit诊断集合，不能把未冻结划分当正式训练划分。

## 放行边界

自动化检查通过只能证明对应数据/接口/流程可用。独立双人审计、近重复阈值校准、G1可修复空间、可训练模型实现及小规模机制信号仍是完整方案的必要证据；未满足时必须报告具体缺口，不能启动大规模训练来绕过。
